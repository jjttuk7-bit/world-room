# 창작 브리프 시작 흐름 설계

## 목적

음성 세션이 맥락 없이 장면을 시작하지 않도록, 작가가 먼저 자유 텍스트로 의도를 남기고 AI가 부족한 정보만 질문해 `오늘의 창작 브리프`를 확정한다.

## 흐름

1. 새 세계 또는 새 세션에서 자유 입력: 만들고 싶은 이야기·장면·감정·인물 중 무엇이든 적는다.
2. 내용이 부족하면 AI가 한 번에 질문 하나만 던진다.
3. 답변을 바탕으로 목표, 갈등, 분위기/문체, 필수 요소, 세션 목표의 5개 필드 브리프를 제안한다.
4. 작가는 브리프를 직접 수정하거나 확정한다.
5. `이 방향으로 음성 대화 시작`을 누를 때만 Realtime 세션을 연다. 첫 인사는 브리프의 어느 지점부터 열지 묻는다.

## 원칙

- AI는 브리프 확정 전 세계의 정식 설정이나 원고를 만들지 않는다.
- 브리프는 세션·세계에 저장되어 초안 생성과 다음 세션의 컨텍스트가 된다.
- 음성 시작은 브리프가 없는 경우 비활성화하고, 작가에게 의도 입력을 안내한다.
