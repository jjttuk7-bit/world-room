# 대화 기반 공동 스토리 제작 설계

## 목표

World Room의 음성 세계관 대화가 `세계 설계`, `장면 초안`, `정식 원고`로 이어지는 공동 창작 과정을 한 화면에서 보여준다.

## 사용자 경험

1. 사용자는 기존처럼 음성으로 AI 동반자와 세계관을 대화한다.
2. 시스템은 전사와 `설정`, `인물`, `갈등`, `장면`, `훅` 단서를 누적한다.
3. 의미 있는 단서가 추가되거나 사용자가 요청하면 AI는 3~6문장의 장면 초안을 제안한다.
4. 사용자는 초안을 채택, 수정 요청, 또는 보류한다.
5. 채택한 초안만 정식 원고에 장면으로 추가되며, 관련 세계 설계도 확정 상태로 남는다.

## 화면 구조

- 왼쪽: 음성 연결 상태와 대화 전사 기록
- 오른쪽 상단: 설정·인물·갈등 카드로 구성된 세계 설계
- 오른쪽 중앙: 제안/수정 중/보류 상태의 장면 초안과 조작 버튼
- 오른쪽 하단: 채택된 장면을 순서대로 보여 주는 정식 원고
- 모바일: 대화 화면을 기본으로 하고 세계 설계, 초안, 원고를 탭으로 전환

## 상태와 저장

- `story_drafts`: 세계별 장면 후보와 원본/수정 계보를 저장한다. 상태는 `proposed`, `revising`, `held`, `accepted`, `superseded`이다.
- `story_scenes`: 사용자가 채택한 장면만 저장한다. `position`으로 원고 순서를 결정한다.
- 초안 생성 실패는 기존 대화와 세계 설계를 보존하며 재시도 안내만 표시한다.
- 수정 요청은 기존 초안을 덮어쓰지 않고 새 버전을 생성한다.

## 생성 정책

- 자동 제안은 새 세계 단서가 추가되어야 가능하며, 짧은 시간에 중복 요청하지 않는다.
- 사용자는 언제든 음성 또는 UI로 수동 제안을 요청할 수 있다.
- Realtime 연결 전과 최소 맥락 부족 시에는 요청을 막고 이유를 표시한다.

## 비목표

- 공동 편집, 사용자 인증/권한 모델, 전문 원고 편집기, 내보내기는 이번 범위에서 제외한다.
- 기존 최근 세계 3개 목록 정책은 유지한다.

## 검증

- 클라이언트: 초안 상태 전환, 원고 반영, 실패 메시지, 요청 조건을 테스트한다.
- 서버: 장면 생성 payload, 수정 버전, Supabase 저장/조회, 순서 계산을 테스트한다.
- 수동: 실제 마이크 대화 후 초안 생성·채택·저장·재접속 흐름을 확인한다.
